BlurzProxyV2 is a browser-based web proxy project powered by Scramjet. Clone the source, configure your own instance, and operate it on infrastructure you control.

View the repositoryRead the setup guide
Independent deployments: this project distributes software, not a centrally operated public proxy. Each operator is responsible for their own users, security configuration, network controls, and hosting-provider rules. Do not expose an instance until its security and deployment requirements have been reviewed.

Clone and customize

Start from the public source repository and adapt the project to your own environment.

Self-host your copy

Follow the local setup or Docker and Caddy deployment instructions in the repository.

Security-conscious defaults

Authentication, origin checks, rate limits, and outbound network controls are part of the project’s security work. Review the current readiness checklist before deployment.
